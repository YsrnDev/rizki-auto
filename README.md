# RizkiAuto - Solusi Pembiayaan Mobil Bekas

RizkiAuto adalah *landing page* premium yang dirancang khusus untuk konsultan pembiayaan otomotif (bekerja sama dengan Mandiri Utama Finance / MUF). Didesain dengan fokus pada konversi (*lead generation*), kecepatan, dan SEO.

## Fitur Utama
- **High-Conversion UI/UX:** Desain modern, bersih, dan memancarkan kepercayaan.
- **Fully Responsive:** Tampilan sempurna di Desktop, Tablet, dan Mobile.
- **Lead Generation:** Dilengkapi form pengajuan 1-kolom dan *Floating* WhatsApp.
- **Advanced SEO:** Terintegrasi dengan Meta Tags, Open Graph (OG), Schema Markup (JSON-LD), Robots.txt, dan Sitemap.xml.
- **Galeri Otomotif:** Halaman `galeri.html` khusus dengan tautan simulasi kredit instan.

## Struktur Direktori
- `index.html` (Beranda & Form Pengajuan Utama)
- `galeri.html` (Katalog Kendaraan)
- `syarat.html` (Syarat & Ketentuan)
- `privasi.html` (Kebijakan Privasi)
- `assets/` (Menyimpan seluruh CSS, JS, dan Gambar)

## Teknologi
- HTML5 (Semantic)
- CSS3 (CSS Variables, Flexbox, Grid)
- Vanilla JavaScript (Lightweight & Cepat)
- Font: Outfit & DM Sans
- Icon: Remix Icon

## Cara Penggunaan / Deploy
Karena berbasis HTML statis murni, *source code* ini dapat langsung di-*deploy* ke layanan hosting gratis mana pun seperti **GitHub Pages**, **Netlify**, atau **Vercel** tanpa memerlukan konfigurasi server/database.
